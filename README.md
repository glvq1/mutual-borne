# Mutual Borne

Borne libre-service des opérateurs Mutual Logistics Allonnes (PWA).
Adresse : https://glvq1.github.io/mutual-borne/

Séparée du dépôt `mutual-connect` pour pouvoir être installée comme une 2ᵉ appli
sur une tablette où Mutual Connect est déjà installée (portées d'installation distinctes).
Les remontées sont envoyées au `doPost()` Apps Script de Mutual Connect (Borne.gs).
